Firmware

The image goes into the slot that is not running and is checked before the board boots it; until then the old one stays the one that boots, so a failed upload or a power cut leaves the board running as before. Takes zephyr.bin of the scope app (build/scope_psu/zephyr/zephyr.bin), the loader (build/loader/loader.bin) or an FPGA image (fpga/tsemac_soc/images/application_update.bin).

FPGA: the golden image at power-up switches to the application image, which an upload replaces. A new application image is tried once and counts as working after it has run 10 s; if it fails to load or hangs, the golden image stays (after a power cycle for a hang), and it can take another upload. The golden image itself is never written over the network.
